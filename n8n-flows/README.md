# n8n flows

Esta carpeta guarda los flujos de n8n en formato JSON para EDwin AI.

## Convenciones

- Un flujo por archivo JSON.
- Nombres en kebab-case, por ejemplo: `buyer-person-agent.json`.
- Mantener los webhooks y responses documentados dentro del nombre o metadata del flujo.
- Antes de importar en n8n, revisar credenciales y URLs sensibles.
